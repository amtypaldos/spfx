QUICK-REFERENCE CONTROL GUIDE
USB audio in → 4 serial effect slots → outFour faders. Physical controls. Effects over USB.

Rocker

hold T + FWD / REVnext / previous effect
Cycles that slot's effect; wraps, includes None. Held rocker repeats after a short delay.

Faders

1–4wet/dry mix of effect slot 1–4
In edit mode: that effect's four parameters.

Channel buttons T1–T4

taptoggle that slot's bypass
hold + rockerchange that slot's effect
FN + Tedit that slot's parameters
Releasing the channel after changing an effect does not toggle bypass. Wet level and bypass state are kept when the effect changes.

Volume

VOL− / VOL+master volume, 2 dB per press
Tap for one step. Hold to repeat.

Play

tapglobal effects bypass

Function (FN)

FN + T1–T4edit that slot's parameters
FN + FWD / REVnext / previous preset (hold to repeat)
tap FN againback to performance mode
hold 1.5 spower off / return to the bootloader

Jacks & USB

Headphone jackaudio output (headphones / speaker)
SYNC jackMIDI clock + Pocket Operator sync OUT. Not audio.
USB-Caudio in from a computer or phone; processed audio goes back to the host.

Signal flow

Four serial stereo effect slots. Each has its own wet/dry fader and bypass.

Effect order when cycling

None → Filter → Chorus → Delay → Reverb → Saturation → Flanger → Bitcrusher → Tremolo → Compressor → Tape wobble → (wraps to None)

Edit parameters

FN + T1–T4 enters parameter editing for that slot. Faders 1–4 become that effect's four parameters.

Tap FN again to return to performance mode.

Effect doesn't fit?

If an effect does not fit the device's DSP memory/CPU, the change is refused and the old effect stays. The four LEDs beside PLAY flash alternately (two on, two off).

Soft takeover

When faders change role the value does not jump. Move the fader until it reaches the stored value; its LED blinks while it waits.

Short bright flash on a dim base: move the fader up. Bright with a short dark gap: move it down. Once picked up, the LED is steady.

LED meaningsMONOCHROME: BRIGHTNESS AND BLINKING ONLY

Performance

Slot LED (beside T1–T4)

off = bypassed (or no effect)   lit = enabled; brighter = more wet

Global bypass

A single LED walks across the four track LEDs.

Four LEDs beside PLAY

Output level. All light at clipping.

Effect selection

Channel held + rocker

The held channel's LED pulses.

Change succeeds

The four LEDs beside PLAY flash all together.

Slot set to None

The four LEDs beside PLAY show a steady dim row.

Change refused

The four LEDs beside PLAY flash alternately.

Preset loaded (FN + rocker)

The four LEDs beside PLAY flash, then a 1–4 LED bar shows your place in the list.

Edit mode

Track LEDs

The four track LEDs show the four parameter values.

LEDs beside PLAY

One LED pulses slowly to show which slot is being edited: LED 1–4 = slot 1–4.
